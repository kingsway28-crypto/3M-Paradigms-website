# 3M Paradigms Consulting Group

**Transforming Knowledge into Impact**

Responsive consulting website built with React, Vite, and Supabase.

## Service pillars
- Management: strategy and organizational development.
- Medicine: clinical research and health systems.
- Markets: business development and market entry.

## Local development
1. Install Node.js 20.19+ or 22.12+.
2. Run `npm install`.
3. Copy `.env.example` to `.env.local` and add the Supabase project URL and browser-safe publishable/anon key.
4. Run `npm run dev`.
5. Run `npm run build` to verify a production build.

Never place a Supabase service-role key in frontend code. Use a browser-safe publishable/anon key with Row Level Security enabled.
